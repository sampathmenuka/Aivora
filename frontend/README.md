# Digital Store Frontend

Next.js frontend for the Java backend in this repository.

## Stack

- Next.js + React + TypeScript
- TailwindCSS (dark mode + responsive)
- Axios
- React Query
- Stripe Elements
- PDF.js (via react-pdf) + HTML5 video preview

## Setup

1. Copy `.env.example` to `.env.local`.
2. Set backend base URL and Stripe key.
3. Install dependencies and run dev server:

```bash
npm install
npm run dev
```

Default URL: http://localhost:3000
